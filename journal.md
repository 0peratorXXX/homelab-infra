### Hardware purchase checklist

For each potential purchase, check:

-   [ ] Exact model and service tag / generation
-   [ ] CPU model and whether it supports the intended workload
-   [ ] RAM type, number of slots, maximum capacity, and upgrade cost
-   [ ] Storage health and whether the SSD is included and working
-   [ ] Drive bays, SATA ports, and mounting hardware
-   [ ] Ethernet speed and any expansion options
-   [ ] BIOS password / firmware lock status
-   [ ] Power-on test, temperatures, fan noise, and physical condition
-   [ ] Power consumption at idle (if practical)
-   [ ] Included power cable and accessories
-   [ ] Total cost including upgrades and travel / postage
